# Project Update & Fix Logs

## Purpose
This directory stores permanent, factual, chronological change logs of all updates, bug fixes, refactorings, and feature additions applied to the codebase.

## Log Entry Requirements
Each log file in this folder must specify:
1. **Timestamp**: Exact date and time when the change was completed.
2. **Author / Agent**: Identity and role.
3. **Problem Statement**: What bug, requirement, or feature was addressed.
4. **Affected Files**: Absolute paths to all files created, modified, or removed.
5. **Detailed Steps**: Step-by-step description of what was changed in each file.
6. **Verification Outcome**: Results of build checks, lint runs, and browser tests.
