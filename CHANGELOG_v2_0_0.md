# CHANGELOG v2.0.0 — Production-Grade Navigation Components Playground

Baseline: `VibTools_WEB_UI_ v1.9.1.zip`
Scope: `Production-Grade Navigation Components Playground (v2.0.0)` only

## Added

- Added `Sandbox/pages/Navigation/` with 8 modular primitive pairs:
  - `sidebar.html` / `sidebar.js`
  - `topbar.html` / `topbar.js`
  - `nav-link.html` / `nav-link.js`
  - `active-link.html` / `active-link.js`
  - `breadcrumb.html` / `breadcrumb.js`
  - `tabs.html` / `tabs.js`
  - `pagination.html` / `pagination.js`
  - `dropdown.html` / `dropdown.js`
- Added `Sandbox/pages/Navigation/navigation-playground.js` module loader.

## Updated

- Rebuilt `Sandbox/pages/navigation.html` into a full-width, scrollable Navigation Component Testing Playground.
- Added scoped navigation playground CSS rules in `Sandbox/css/vibtools-sandbox.css`.
- Synced visible runtime version tags and current documents to `v2.0.0`.

## Preserved

- No app shell, sidebar width, topbar height, auth layout, forms playground, cards playground, docs, upload, settings, monitoring, logs modal, table behavior, backend/API logic, route workflow or dependency model was redesigned or removed.
