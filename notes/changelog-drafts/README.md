# Changelog Drafts Directory

## Purpose
The `notes/changelog-drafts/` directory is used for drafting, reviewing, and staging version changelogs before they are officially finalized and published to root changelogs (`CHANGELOG_*.md`).

## Workflow
1. Write draft notes when features or fixes are in progress.
2. Group changes by:
   - Added
   - Changed
   - Fixed
   - Synchronized Docs
3. Once the release or milestone is approved, migrate content to the main repository changelog.
