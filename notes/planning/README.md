# Planning Directory — Pre-Implementation Blueprints

## Purpose
The `notes/planning/` folder stores all pre-implementation plans, architectural outlines, component scopes, and risk evaluations created before writing code.

## Requirements
- Every new feature, page, or bug fix must have a planning document here before changes begin.
- Include:
  - **Objective**: What is being built or fixed.
  - **Scope Boundary**: Explicit list of files to touch and files that must NOT be touched.
  - **Step-by-Step Implementation Strategy**: Phase 1, Phase 2, etc.
  - **Verification Criteria**: Specific checks to pass after completion.
