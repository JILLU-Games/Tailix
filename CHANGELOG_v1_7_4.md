# Changelog — VibTools Web UI v1.7.4

## Scope Lock
Compact Typography & Restrained Color Hierarchy only.

## Before → After

- Page titles on `upload.html`, `docs-layout.html`, and `settings.html`: oversized/visually loud → locked to `18px`, `600`, `1.3` line-height.
- Section headings: brighter/larger than compact target → locked to `14px`, `600`, `1.4` line-height.
- Body/descriptive text: high-brightness visual noise → muted to `#8B949E` at `12px` with `1.5` line-height.
- HTTP method badges: vivid/neon accent states → desaturated 12% fill with restrained border opacity.
- Upload file extension badges: type colors competed with content → neutral `#161B22` fill, `#8B949E` text and `#30363D` border.

## Preserved

No layout, routing, sidebar width, topbar height, zero-shadow contract, upload behavior, docs API playground structure, settings sticky sidebar, auth surfaces, JavaScript workflow, or component semantics were changed.
