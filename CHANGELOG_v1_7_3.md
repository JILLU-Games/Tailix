# Changelog — VibTools Web UI v1.7.3

## Scope
Zero-Shadow Pure Flat UI Standard only.

## Updated
- Added a global zero-shadow CSS guard: `box-shadow: none !important` and `text-shadow: none !important` for all elements and pseudo-elements.
- Removed runtime auth card, modal, alert indicator, upload row, upload dropzone, social button, switch and form-control focus shadow/elevation treatment.
- Removed upload dropzone hover translation so no component visually lifts off the canvas.
- Synchronized visible Sandbox version badges, runtime navigation version, tokens, component docs, validation and audit records to `v1.7.3`.

## Preserved
- Sidebar width, topbar height, routing, page structure, component markup, app-page/auth-page alignment, settings sticky navigation, upload component behavior, docs architecture and JavaScript workflow remain unchanged.
