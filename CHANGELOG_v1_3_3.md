# Changelog — VibTools WEB UI v1.3.3

## Scope lock

Only Sandbox Web app UI/UX typography, text color, spacing and density repair was changed.

No page, feature, workflow, architecture, file structure, dependency, behavior, or component naming was removed or replaced.

## Fixed

- Normal body/description text hierarchy calibrated to `#C9D1D9` while retaining `#F8FAFC` primary text and `#8B949E` muted text.
- Source docs content token `#D8DEE9` preserved as a named token for reference compatibility.
- Hero titles capped to 24–26px.
- Page H1 compacted to 22–24px.
- H2/H3 weights reduced to avoid oversized/heavy SaaS-style headings.
- Body text set to 13px with compact 1.46 line-height.
- Page-header description top spacing reduced from 12px to 8px.
- Global section spacing reduced to 16px and first-content spacing tightened.
- Grid/component gap normalized to 8px instead of arbitrary 9px.
- Main shell content gutter reduced from 12px to 10px.
- Table text and header weight normalized to the Step-1 density contract.
- Dashboard stat weight reduced while preserving compact card geometry.
- Typography/colors sandbox page updated to show the corrected v1.3.3 scale.
- Visible sandbox version labels updated to v1.3.3.

## Preserved

- Tailwind CDN framework.
- Sandbox pages and navigation structure.
- Sidebar width: 196px.
- Topbar height: 44px.
- Button height: 30px.
- Input height: 32px.
- Card padding: 10px.
- Card radius: 12px.
- Canonical brand colors: `#0D1117`, `#161B22`, `#21262D`, `#30363D`, `#F8FAFC`, `#8B949E`, `#2563EB`, `#38BDF8`.
