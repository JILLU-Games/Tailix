# CHANGELOG v1.4.7 — Contact Page Alignment, Interactive Links & Spacing Polish

## Baseline

- Started from `VibTools_WEB_UI_v1.4.6.zip`.
- Scope was locked to Contact page UI design and its supporting contact-specific CSS contracts only.

## Updated

- Updated `contact.html` Contact and Social cards from plain body text rows to compact key/value rows.
- Added `.vib-link` interactive value styling for URLs, social handles, email and telephone values.
- Added contact-specific layout contracts: `.vib-contact-layout`, `.vib-contact-column`, `.vib-contact-list`, `.vib-contact-row`, `.vib-contact-detail-stack`, `.vib-contact-form-fields` and `.vib-contact-actions`.
- Wrapped Address details in `.vib-card-subtle` nested detail panels to match the current 3-tier surface system.
- Normalized the Message form field rhythm to the compact form standard: `8px` field stack, existing `3px` label-to-input gap and `12px` action margin.
- Synchronized visible/runtime/static version strings to `v1.4.7`.
- Updated validation and forensic documentation for the v1.4.7 scope.

## Not changed

- No sidebar width/topbar height changes.
- No route, workflow, dependency, file-structure or architecture changes.
- No global card/form/table/docs redesign outside Contact page scope.
- No typography scale, global spacing scale, radius, shadow or gradient changes.
