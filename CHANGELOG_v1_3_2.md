# CHANGELOG v1.3.2 — Sandbox Global Component Compact Repair

Baseline: `VibTools_WEB_UI_v1.3.1.zip`.

## Fixed

- Reduced header, sidebar, title, body, table, form, card and section density further.
- Reduced sidebar width from 216px to 196px and added a global icon slot for every sidebar link.
- Left-aligned shell containers to remove excessive whitespace between sidebar and content.
- Changed form/input/nested surfaces from direct canvas background to `#11161D` field surface.
- Reduced card padding from 12px to 10px and page/grid/section gaps globally.
- Updated docs/dashboard/contact/cards/tables through the shared component layer instead of page-specific styling.
- Updated validation to lock v1.3.2 compact fragments.
