# User Guide Directory — A-Z End-User Operational Guidelines

## Purpose
This directory contains step-by-step user manuals explaining how to use every screen, button, table, form, modal, and feature in the application.

## Directives
- **Exact Interaction Guidance**: Explain what happens when a button is clicked, what inputs expect, and how to filter/navigate.
- **Visual & Functional Truth**: Every guide must describe the exact current UI as implemented, without assumptions.
- **Coverage**:
  - Dashboard navigation and sidebar collapsing.
  - Data table sorting, searching, and batch operations.
  - Form validation rules and file upload interactions.
  - User and team management actions.
  - Server monitoring interpretation and metric views.
