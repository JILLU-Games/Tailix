# Developer Guide Directory — Architecture, Tokens & Implementation

## Purpose
This directory contains comprehensive guides for engineers, UI developers, and AI agents extending or maintaining the application.

## Directives
- **Zero Arbitrary Values**: How to use `--vib-*`, `--icon-*`, and `--text-*` variables properly without breaking design system rules.
- **Component Lifecycle**: How to register new components adhering to `components/component-contracts-tailwind-cdn.md`.
- **Layout Shell Usage**: How to leverage `shell-manager.js` with `data-vib-shell`.
- **Event Bus Integration**: How to subscribe to and trigger events via `window.EventBus`.
